spec <object> (required)	# GarageReplicationSpec defines the desired state of GarageReplication. GarageReplication copies objects between two independent Garage clusters through their S3 APIs, for replication and migration. It is not a backup: there are no point-in-time snapshots and no restore, and in mode Mirror a deletion or an overwrite on the source reaches the destination on the next run. Each run executes one Kubernetes Job per bucket in the GarageReplication's namespace, so the Jobs need network access to both S3 endpoints. Only objects (and their user metadata) are copied: buckets, keys, permissions, quotas, website and lifecycle configuration are not. Deleting a GarageReplication never deletes object data on either side.
